🔗 ตั้งค่า Google Sheets Sync
ℹ️ สร้าง Google Apps Script ครั้งเดียว แล้ว Sync ได้ทุกเครื่อง ทุกที่
🔄 Sync ข้อมูล
⬆️ Push ขึ้น Sheets

ส่งข้อมูลจาก Browser → Google Sheets (เขียนทับข้อมูลเก่าใน Sheets)

⬇️ Pull จาก Sheets

ดึงข้อมูลจาก Google Sheets → Browser (เขียนทับข้อมูลเก่าใน Browser)

📋 คู่มือสร้าง Google Apps Script (ทำครั้งเดียว)
⚠️ ต้องทำขั้นตอนนี้ก่อน 1 ครั้ง จึงจะ Sync ได้
1เปิด sheets.new → สร้าง Google Sheets ใหม่ → ตั้งชื่อว่า "โกหนุ่ม เซอร์วิส"
2คลิกเมนู Extensions → Apps Script
3ลบโค้ดเดิมทิ้งทั้งหมด แล้วกด คัดลอกโค้ด ด้านล่าง วางลงไป
▼ Apps Script Code
4คลิก Deploy → New deployment → Type: Web app → Execute as: Me → Who has access: Anyone → กด Deploy
5คัดลอก Web app URL ที่ได้ → นำมาวางในช่อง URL ด้านบน → กด บันทึก URL
6กด ทดสอบ แล้ว Push ขึ้น Sheets ได้เลย ✅
